# 🎬 Pelispacio - Tu Espacio de Cine Digital

## 📝 Descripción
Este proyecto es un sitio web completo dedicado al entretenimiento cinematográfico. Permite a los usuarios explorar una cartelera interactiva de películas y series, consultar planes de suscripción y rellenar formularios de contacto, ofreciendo una interfaz limpia y atractiva con temática oscura ideal para los amantes del cine.

## 📁 Estructura del Proyecto
El repositorio está estructurado de manera organizada para separar la lógica, los estilos y las interfaces:
* **`/pages`**: Contiene las secciones del sitio (Películas, Series, Animes, Formularios y Planes).
* **`/styles`**: Hojas de estilo CSS personalizadas para el diseño responsivo y la estética del sitio.
* **`/scripts`**: Archivos JavaScript para la interactividad de la página.
* **`/images`**: Banco de imágenes con los pósters oficiales de las películas y logotipos del sitio.

## 🚀 Tecnologías Utilizadas
* **HTML:** Estructura semántica de las secciones y el catálogo.
* **CSS:** Diseño adaptado a dispositivos móviles (Responsive Design) y estilos modernos para las tarjetas de películas.
* **JavaScript:** Interactividad y manejo de acciones en el sitio web.
